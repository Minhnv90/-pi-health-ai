Trợ lý AI sức khỏe

Khi bật tính năng này, nội dung bạn gửi sẽ được chuyển tới AI provider thông qua API của Health SI. Không gửi dữ liệu định danh hoặc hồ sơ bệnh án.

Chỉ cần điền địa chỉ API một lần; ứng dụng sẽ nhớ trên thiết bị này. Không nhập API key.

Câu trả lời AI sẽ hiển thị tại đây sau khi API được triển khai.
